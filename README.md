# 🎮 Starfield Language Tools

A simple and effective application to easily change the language settings of Bethesda's Starfield game. Created because Bethesda Game Studios didn't include a straightforward language option, this tool provides quick language switching directly from a friendly interface.

---

## 🚀 Features

- ✅ **Change Game Language** effortlessly
- ✅ **Change Audio Language** (Supported: English, Spanish, German, French, Japanese)

---

## 🛠️ Technologies Used

- **Python**
- **tkinter** (GUI)
- **PyInstaller** (for building executable)

---

## 🖥️ Supported Platforms

- ✔️ Windows

---

## 📥 Download

Download the latest Windows release from the [Releases Page](https://github.com/gustavofalcao1/Starfield-Language-Tools/releases).

---

## ▶️ Running the Application

### Run from source

1. Ensure Python is installed.
2. Run the application:
```bash
python main.py
```

### Build executable (optional)

To create a standalone executable file:
```bash
pyinstaller --name="Starfield-Language-Tools" --onefile --windowed main.py
```

The executable will be available in the `dist/` directory.
